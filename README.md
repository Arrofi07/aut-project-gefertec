🚀 AI-Assisted Monitoring for Wire Arc Additive Manufacturing (WAAM)

This project, developed in collaboration with TU Berlin and Gefertec, focuses on implementing AI-based methods for real-time monitoring and characterization of the WAAM (Wire Arc Additive Manufacturing) process.

🔹 Key Features & Contributions
Real-time Process Monitoring: AI-powered object detection (YOLO) and segmentation (Yolact) for analyzing welding videos.
Time-Series Analysis: Tracking melt pool size, arc behavior, and spatter formation.
Data Cleaning & Annotation: Using FiftyOne and CVAT for high-quality dataset preparation.
3D Reconstruction & Surface Analysis: Exploring NeRF for geometry reconstruction and DIC/DIP for surface texture recognition.

📂 Technologies Used
Deep Learning: YOLO, Yolact
Computer Vision: OpenCV, PyTorch
Data Annotation: FiftyOne, CVAT
3D Reconstruction: NeRF
Time-Series Analysis: Pandas, NumPy

📌 About WAAM & Its Importance
WAAM is an advanced additive manufacturing technique that enables cost-effective and flexible production of large metallic parts. AI-based monitoring ensures high precision, reduces material waste, and enhances process stability.
